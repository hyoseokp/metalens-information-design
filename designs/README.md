# Published designs

Three width maps from the paper, all on the same SiN platform:

| file | description |
|---|---|
| `hyperbolic_reference.pt` | 600 nm hyperbolic phase, projected onto the feasible set |
| `information_design.pt` | target-information optimized (v5d production, seed 20260805) |
| `mtf_volume_control.pt` | broadband MTF-volume proxy (v5d production, seed 20260805) |

All three share the same material, height, pitch, width bounds and field
quadrature. The only difference is the objective used to optimize the width map.
